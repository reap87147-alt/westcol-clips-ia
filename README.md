# WestCOL Clips IA

Sistema para analizar directos de Kick y encontrar automáticamente momentos interesantes para convertirlos en clips verticales.

## Objetivo

1. Recibir un enlace de un directo o VOD.
2. Obtener el video.
3. Transcribir el audio.
4. Detectar momentos interesantes.
5. Seleccionar los mejores clips.
6. Recortar los videos.
7. Prepararlos en formato vertical para Shorts/Reels.
8. Generar títulos y descripciones.

## Flujo

Kick → Video → Transcripción → IA → Mejores momentos → Clips → Publicación
